# Security Policy

## Reporting a vulnerability

Please do not report security vulnerabilities through public GitHub issues.

Use GitHub's private vulnerability reporting for this repository:

https://github.com/EvChurch/website/security/advisories/new

Include the affected route or component, reproduction steps, potential impact,
and any suggested mitigation. Do not include personal data, production
credentials, or live payment details in the report.

## Supported version

Security fixes are applied to the current `main` branch and the production
release derived from it. Older revisions are not supported.
