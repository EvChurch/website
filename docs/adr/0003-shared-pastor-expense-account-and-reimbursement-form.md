# Shared Pastor Expense Account and simplified reimbursement form

Use one shared Pastor Expense Account purpose available to anyone who can submit reimbursements, replacing the proposed staff/apprentice eligibility checks and person-specific accounts. Claims against this purpose go directly to finance approval; ordinary purposes retain purpose approval followed by finance approval. A claimant cannot approve their own claim. This deliberately permits the shared purpose to bypass purpose approval, with finance retaining review of each claim.

Show the saved payout account holder name and a masked bank account number in a compact row on the report form (first two and last five digits visible, with an eye/eye-slash toggle to show or hide the full number), with “Use a different account for this report” to specify an override. The override applies only to that report and leaves payment settings unchanged. Fix the payout details for each submission so later payment-settings changes do not redirect an already submitted report. Continue restricting bank-detail visibility to the claimant and finance.

The expense table defaults to one “Amount” field for the receipt total. New expense lines default to including GST. An “Advanced” switch above the table (on the right beside Add expense on desktop; below the Expenses heading on the left with Add expense on the right on mobile) is available to any claimant and reveals net amounts and the per-line GST controls. Hiding the controls preserves existing amounts and GST choices; it does not reset them.

The website owns this shared purpose so Rock directory refreshes cannot revoke it for lacking an assigned purpose approver. Ordinary purposes remain managed by Rock.
