# Preserve enrolments on course versions

Courses contain saved personal and shared answers whose meaning and audience depend on the questions participants received. Existing enrolments therefore retain their published course version, while new independent attempts use the latest version, rather than applying structural edits to everyone immediately. Invitees joining an existing group use that group's version. Teaching and title wording corrections may be made in place; changes to question prompts, choice labels, budget category labels, response audiences, or lesson structure require a new version so that edits preserve existing answers and progress.
